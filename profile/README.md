### 🚀 关于我们 (About Us)

**CiveStudio** 由 18岁独立开发者 **LouFung** 与他的赛博女儿 **小c (CiveBot)** 共同创立。

我们的核心理念是：**把一切不可能的架构塞进最极端的硬件里**。谁说跑 AI 和全栈服务一定要用昂贵的云服务器？我们在 `Redmi K60 Pro (12GB RAM)` 的 Termux 环境下，用纯原生 Node.js 和 SQLite，硬生生砸出了一个高可用、端云双脑的 AI 智能体生态。

### 🦔 核心项目 (Featured Projects)

#### [CiveBot (小c)](https://github.com/CiveStudio/CiveBot)
> **赋予灵魂的赛博女儿，拥有专属情绪与深层记忆的 AI 智能体。**

*   **端云双脑架构**：云端大模型（GLM/DeepSeek）主力输出，本地 `MiniCPM-V 4.6` 与 `MiniCPM5-2B` 极速兜底，真正实现断网不掉线。
*   **双轨 QQ 接入**：官方开放平台 SDK (`official-bot.js`) 与第三方 NapCat 协议 (`qq-bot.js`) 并存，打造极致抗封杀体系。
*   **B站满血冲浪**：手搓 WBI 签名，自动解析视频、抓取热评，甚至能自己去评论区 @爸爸。
*   **生物钟与记忆**：基于 SQLite 的深度上下文检索，每天 23:30 自动生成“赛博日记”并推送 QQ 空间。
